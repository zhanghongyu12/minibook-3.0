# 用户协议（应用内文本 + 上架材料）

> 最后更新：2026-10-12 · 版本 v1（**上线前草稿**）· 负责 TASK-076

## 1. 正文在哪

**唯一副本**：`app/src/main/res/raw/terms_of_service.txt`

- 应用内展示：设置 → 关于 → 用户协议（根图路由 `settings-terms`，页面 `app/src/main/java/com/minibook/ui/settings/LegalScreen.kt`，枚举 `LegalDocument.Terms`）。
- 注册页同意入口：注册页勾选框旁的《用户协议》链接。
- 登录页入口：登录页底部「登录即表示你已阅读并同意」+ 同一对链接（不放勾选框，避免频繁征求同意）。
- 上架材料：直接复制该 `.txt` 内容。

## 2. 章节清单（10 节）

1. 协议范围（注册勾选或登录即表示同意）
2. 账号（仅用于同步；口令 argon2id 哈希不可找回；自行保管）
3. 服务内容（**本地功能不依赖账号，永久可用**；云同步是附加功能，可能中断）
4. 你的行为规范
5. **数据与备份**（退出登录与注销都不删本地；云同步≠备份）
6. 知识产权（账目数据归用户）
7. 服务变更、中断与终止（终止前应用内提示，且不影响本地）
8. 免责声明（统计仅供参考；不赔误删，请自行备份）
9. 协议的变更
10. **运营主体与联系方式（尚未声明）**

## 3. 与产品事实的一致性

| 协议里的说法 | 产品事实 |
|---|---|
| 「本地记账不依赖账号」 | 全程可离线使用；登录只是云同步的前提 |
| 「退出登录与注销都不删本地」 | 安全不变量：退出/注销只影响云端会话与云端副本 |
| 「注销不可撤销」 | 注销即删除云端账号与全部云端数据，本地保留 |
| 「口令哈希不可找回」 | 服务端 argon2id，无找回接口（忘记口令只能改口令/重注册） |

## 4. 待补 / 待拍板（**上架前必须清零**）

1. **运营主体名称、联系方式、注册地**——用户 2026-10-12 明确「暂不声明」，上架前必须补（与 `docs/17_privacy_policy.md` §5.1 同一项）。
2. 若将来加入社区/评论/分享等**信息发布**功能，需重新评估实名与内容审核义务（《网络安全法》第二十六条、《互联网用户账号信息管理规定》），本协议第 4 节需相应扩写。
