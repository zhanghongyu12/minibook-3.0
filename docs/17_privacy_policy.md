> 最后更新：2026-10-12 · 版本 v1（**上线前草稿**）· 负责 TASK-076

## 1. 正文在哪

**唯一副本**：`app/src/main/res/raw/privacy_policy.txt`

- 应用内展示：设置 → 关于 → 隐私政策（根图路由 `settings-privacy-policy`，页面 `app/src/main/java/com/minibook/ui/settings/LegalScreen.kt`，枚举 `LegalDocument.Privacy`）。
- 注册页同意入口：注册页勾选框旁的《隐私政策》链接（`app/src/main/java/com/minibook/ui/settings/RegisterScreen.kt`）。
- 上架材料：直接复制该 `.txt` 内容，**不要另写一份**（两份必然漂移）。

本文件只记录「谁负责、有哪些硬要求、还差什么」，不复制正文。

## 2. 章节清单（11 节）

1. 一句话承诺（本地优先）
2. 我们收集哪些信息（本地不收集 / 只有云同步才上传账目）
3. 我们明确不做的事（不读通讯录位置相册剪贴板、不接广告 SDK、不第三方共享、不上传短信原文与 IMAP 凭据）
4. 短信账单功能（可选、默认关闭、解析全在本机）
5. 邮箱账单导入（可选、只读拉取、凭据只在本机）
6. 权限说明（READ_SMS / RECEIVE_SMS / POST_NOTIFICATIONS / INTERNET / 指纹面容）
7. 数据存储与安全（SQLCipher 本地加密、argon2id 口令哈希、正式版 HTTPS）
8. 你的权利（查阅更正 / 注销即删云端而本地保留 / 退出登录即撤回 / 导出）
9. 未成年人
10. 本政策的变更
11. **运营主体与联系方式（尚未声明）**

## 4. 与代码的一致性（改代码时同步检查）
